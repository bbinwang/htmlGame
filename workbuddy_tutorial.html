三 · 专家和技能
专家 · 封装好的垂直 Agent
  • 专家 = 一个专业领域的完整 Agent
  • 内置 100+ 专业领域 AI 专家
  • 按行业分类，每个专家有能力卡片
  • 举例：微信小程序专家、高考志愿专家、资讯速递专家
三 · 专家和技能
专家中心
  • 按行业浏览专家列表
  • 点击进入专业对话
  • 拥有行业知识 + 技能 + 最佳实践
  • 也可以自定义创建专家，封装你的方法论
三 · 专家和技能
专家团 · 多 Agent 协作
  • 专家团：一群 Agent 一起协作
  • 团长自动拆任务 → 分配专家 → 并行跑 → 整合结果
  • 举例：软件开发团队 — 交付总监 + 产品经理 + 架构师 + 工程师 + QA
  • 积分消耗约 3-5 倍单专家（多 Agent 通信成本）

  • 打开「对话记忆」
  • 从对话中提取关键信息
  • 越用越了解你的习惯和偏好
  • 支持从其他 Agent 导入记忆，搬家很方便
四 · 修改设置
推荐设置 · 自定义指令
  • 自定义指令 = Agent 的最高级规则文档
  • 推荐使用卡帕西（Karpathy）模板
  • 核心原则 ①：先思考再写代码 — 不假设，不隐藏困惑
  • 核心原则 ②：简洁优先 — 用最少代码解决问题
  • 核心原则 ③：精准修改 — 只动必须动的地方
  • 核心原则 ④：目标驱动 — 定义成功标准，循环验证

七 · 远程控制
远程控制 · 实际场景
  • 在外面，需要把电脑文件发到邮箱
  • 手机上跟 WorkBuddy 说一声 → 自动读取 + 发送
  • 也可以发到小程序对话框
  • 前提：提前配置好 QQ 邮箱连接器
  • 支持飞书、钉钉、QQ 接入助理
